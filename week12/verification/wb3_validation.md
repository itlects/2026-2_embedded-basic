# 워크북 3 검증

- Arduino CLI 1.6.0 / Arduino-ESP32 3.3.2 / esp32:esp32:esp32
- DHT sensor library 1.4.6 / Adafruit Unified Sensor 1.1.15
- ESP32 타깃 컴파일·링크 통과: Flash 952223 bytes, RAM 45344 bytes.
- 실제 스케치의 버튼·음악·센서 함수를 호스트 C++에서 가짜 시계·입력·출력으로 실행한 8개 동작 점검 통과. 디바운스, 짧게/길게 구분, 곡 변경, 정지, 자동 종료, 음악 중 버튼, 전체 끄기, 센서 주기.
- 내장 웹페이지 JavaScript 구문 검사 통과.
- 실물 회로·부저 음량·모바일 접속·실제 HTTP 요청은 하드웨어가 없어 미검증.
- 피에조 부저를 기준으로 작성. 자기식 부저/스피커는 드라이버 회로 없이 GPIO에 직결하지 않는다.
