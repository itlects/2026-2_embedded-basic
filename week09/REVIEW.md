- 예제 4 호스트 시뮬레이션: 바운스 6ms 입력 → 토글 1회, 경보 1초 주기·150ms, 정지 시 LED 꺼짐 확인.
- 핀 기능은 Espressif DevKitC V4 User Guide J2/J3 표와 대조.
- **미검증**: 실제 보드 업로드, 부저 음량, 실측 ADC 값 → 수업 전 교수자 확인 필요.

## D. 2차 검토 (2026-11-04) — 시리얼 통신 학습목표 반영
요청 학습목표: ① 시리얼 통신 공통 원리, UART·I2C·SPI·1-Wire 신호선·속도·장단점 비교 ② 시리얼 모니터 센서값 송신 + PC 명령 수신 릴레이 제어(양방향).

|---|---|---|
| 시리얼 공통 원리 | 없음(USB-UART 브리지 한 줄) | 이론 Part B 1절 + 그림 s1 |
| 4방식 신호선·속도·장단점 비교 | 없음 | 비교표 + 그림 s2 |

| 양방향 통신 + 릴레이 실습 | 없음 | 예제 5 / 워크북 5 (ESP32·UNO 공용 코드, 연결도 2종) |

추가 고려: ESP32(3.3V)에 5V Active-LOW 릴레이 모듈을 쓰면 HIGH로 완전히 꺼지지 않을 수 있어, OFF 시 핀을 INPUT(고임피던스)으로 바꾸는 relayWrite()를 넣고 UNO 대안을 함께 제시했다. SPI CS는 부팅 스트랩 GPIO5 대신 GPIO4를 사용했다.
