# 7주차 — 인터럽트 처리

## 학습목표
인터럽트 벡터, ISR 실행 절차를 이해하고 버튼 3개의 인터럽트 이벤트를 활용한 카운터와 소프트웨어 시계를 구현한다.

## 구성
- `examples/`: 기본 인터럽트 및 타이머 예제
- `labs/`: 시계, 증가·초기화·일시정지 카운터 통합 실습
- `workbooks/`: 학생용 단계별 실습 가이드
- `images/`: 전기 연결 확인용 SVG 연결도

## 주의
Arduino UNO(ATmega328P)의 외부 인터럽트 INT0/INT1는 D2/D3 두 개뿐이다. 3버튼 인터럽트 실습은 D2,D3,D4의 핀 변경 인터럽트(PCINT)를 사용한다. ESP32 DevKit의 3버튼 실습은 GPIO18,19,21의 GPIO 인터럽트를 사용한다. 모든 버튼은 `INPUT_PULLUP` 상당의 풀업을 이용하고 버튼의 반대편을 GND에 연결한다. UNO에는 5V, ESP32에는 3.3V 논리 레벨만 인가한다.

**검증 구분:** 문서/배선 로직 검토용 자료이며, 실제 실물 보드 테스트는 별도로 수행해야 한다.
