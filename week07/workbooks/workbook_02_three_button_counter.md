# 워크북 2: 시계와 3버튼 인터럽트 카운터
## 준비물
UNO 또는 ESP32 DevKit, 푸시 버튼 3개, 브레드보드, 점퍼선, USB.
## 배선 및 기능
|기능|UNO|ESP32|접속|
|---|---|---|---|
|카운터 +1|D2 (PCINT18)|GPIO18|핀 → 버튼 → GND|
|초기화 0|D3 (PCINT19)|GPIO19|핀 → 버튼 → GND|
|일시정지/재개|D4 (PCINT20)|GPIO21|핀 → 버튼 → GND|
각 입력은 `INPUT_PULLUP`; 버튼을 누르면 HIGH → LOW. 신호선은 다른 전원 레일과 연결하지 않는다. 세 버튼의 접지선은 GND 레일 하나에 모으고 레일은 MCU GND에 연결한다. 단선 레일은 점퍼로 이어야 한다.
## 학습 수행
1. 전원을 분리한 상태에서 버튼을 중앙 홈을 가로지르게 놓고 위 표대로 결선한다.
2. `labs/uno_03_buttons_pcint` 또는 `labs/esp32_03_buttons_gpio` 스케치를 열어 업로드한다.
3. 시리얼 모니터를 115200bps로 설정하고, 시계가 매초 증가하는지 확인한다.
4. 증가 버튼 5번: COUNT=5. 초기화: COUNT=0. 일시정지: PAUSE ON. 정지 중 증가: 변화 없음. 다시 일시정지: PAUSE OFF. 증가 버튼: COUNT=1.
5. 버튼을 길게 눌러도 한 번만 동작하는지, 빠르게 연속 누를 때의 한계를 관찰한다.
6. 회로의 단선, 반대편 접점 미연결, GND 분리, 사용 금지 GPIO 등의 오류를 확인한다.
## 이론 정리
- UNO의 D2/D3에는 INT0/INT1도 존재하지만 본 실습은 D4까지 세 입력을 묶기 위해 PCINT2 그룹을 사용한다.
- ISR은 에지를 비트 플래그로 기록하고 메인 루프가 30ms 안정 상태를 확인한다. 30ms는 실습값이며 스위치 종류에 따라 조정한다.
- `volatile`은 최적화를 막지만 여러 명령으로 이루어진 동작의 원자성은 보장하지 않는다.
- 카운터만 정지하며 시계는 지속된다. 카운터를 자동 증가시키는 타이머 실습이 아니다.
