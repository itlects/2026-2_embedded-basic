# 워크북 1: 인터럽트와 시계 만들기
## 목표
버튼 하강 에지 인터럽트가 ISR을 호출하는 순서를 설명하고 `millis()`로 1초 간격 시계를 구현한다.
## 준비물
Arduino UNO 또는 ESP32 DevKit, 버튼 1개, 브레드보드, 점퍼선, USB.
## 연결
- UNO: D2 → 버튼 접점 A, 버튼 접점 B → GND
- ESP32: GPIO18 → 버튼 접점 A, 버튼 접점 B → GND
- 택트 스위치 같은 면 2핀은 내부적으로 연결됨. 맞은편 면과 접점을 사용하며 브레드보드 중앙 홈 양쪽으로 다리를 배치.
- 내부 풀업 사용. 외부 5V/3.3V 직결 금지.
## 실습
1. Arduino IDE로 해당 보드를 선택하고 보드 지원 패키지를 설치한다.
2. `examples/uno_01_external_interrupt` 또는 `examples/esp32_01_external_interrupt`의 스케치를 연다.
3. 115200bps 시리얼 모니터를 열고 한 번 누를 때 출력 횟수를 관찰한다. 접점 바운스 때문에 중복 출력될 수 있다.
4. `examples/*_02_clock`을 업로드하여 1초마다 시계가 출력되는지 확인한다.
5. `delay(1000)`를 넣었을 때와 없는 상태에서 입력 처리 반응을 비교한다.
## 질문
인터럽트 벡터의 역할은 무엇인가? 왜 ISR 안에서 시리얼 출력과 지연 함수를 피해야 하는가? `millis()`를 RTC라고 부를 수 없는 이유는?
